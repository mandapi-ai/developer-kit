# P4.1 official reference validation — 2026-10-02

This report records a real public-source crawl after the dedicated official adapters and conservative seller-scoped matching were added. The P4 V2 `prices.csv` layout remains unchanged. Results are dated observations, not permanent billing promises.

The OpenAI adapter uses the public full Markdown pricing table and preserves short/long context plus named service tiers. Anthropic keeps 5-minute and 1-hour cache-write rates separate in `offer-details.csv`. Google exports paid text-token offers with context, service and active-date dimensions; free quotas, audio/image charges and storage-only offers are excluded. DeepSeek keeps peak/off-peak time bands and cache-hit/miss distinctions. Dedicated extraction yields `public_source`; generic HTML candidates keep `needs_review`.

## Validation and local research package

- Python 3.13 editable install and the complete pytest suite: 102 passed, 0 failed.
- Both V2 snapshots passed `mandapi-price-intel validate`; matched and local Hugging Face V3 exports completed.
- Original currencies stay BRL/USD/CNY; no implicit FX spread is calculated. Missing fields remain blank, not zero.
- Each fetch keeps URL, time, HTTP status, response SHA-256, adapter, parser status and row count in local `evidence.jsonl`. All 1,625 global `offer-details.csv` rows match their source's exact fetch timestamp; matching refuses missing or stale sidecars.
- Local outputs: `dist/2026-10-02-p41-brazil-verified/`, `dist/2026-10-02-p41-global-verified/`, `dist/2026-10-02-p41-matched-final/`, and `dist/huggingface-v3/` under the Skill directory. Crawl outputs and third-party page copies are ignored by Git. No Hugging Face upload or daily scheduling was performed.

## Remaining limitations

- HTML-derived MandAPI, Roteia and RunAPI prices still require review. `public_source` means deterministic extraction from a public source, not independent billing verification.
- Anthropic table rows without a linked official model ID are omitted; rolling aliases are not silently merged with dated snapshots.
- Google export is limited to paid text-token pricing; free access, audio/image units and storage-only charges are outside the V2 token schema.
- DeepSeek publishes a `deepseek-v4-pro` price table, while a separate recent announcement discusses temporary routing at V4.1 Flash rates. The table values are retained as published; actual billing is not inferred. This model is not currently in the curated cross-seller alias list.
- OpenAI promotional status and service/context tiers remain distinct; a promotion is not treated as a permanent standard rate.
- Alias registry covers 41 seller-scoped IDs across ten matched canonical models; unmatched variants remain unresolved. This is a deliberately narrow comparable sample.
- One existing public source, UnoRouter, returned HTTP 403 in P4 and is not bypassed; current crawl evidence records its status.
- `packages/codegen`, `packages/catalog`, pnpm configuration and production services were not modified.
