# MandAPI

One API for multiple AI models.

GPT · Claude · Gemini · DeepSeek · Kimi

Developer tools:

- SDK
- Code Generator
- Model Catalog
- Agent Skills

MandAPI is a multi-model AI gateway and developer platform. This repository is the starting point for its developer tools. The packages and tools listed above are planned; no SDK, generator, catalog, or skill is published from this repository yet.

## Project status

This repository currently contains its initial documentation and an empty packages/ directory. Implementation will be added in stages, beginning with code generation, a model catalog, and a model schema. Model and protocol support will be documented as each component is released.
